# ADR-0017：qwen3-asr-1.7b 作为默认本地模型的候选，参加 ADR-005 的实测

产品负责人点名希望用 qwen3-asr-1.7b 做手机内置转录模型。决定把它列为 ADR-005（默认本地模型）的候选，而不是现在就定为默认。默认模型在 G2 前用实测数据决定：在产品负责人的三台目标手机（鸿蒙 NEXT、iOS、Android）上，用同一批耳机录制的中文音频，比较识别质量、内存峰值、冷启动时间、转录耗时和发热。对比对象至少包括 qwen3-asr 的小尺寸版本和 SenseVoice。

## Considered Options

- **直接定 qwen3-asr-1.7b 为默认**：否决。1.7B 参数的模型在手机上的内存占用和速度没有实测数据；它能否经 sherpa-onnx 在三端运行尚未核实；权重许可证也未核对。
- **不考虑该模型，只测 PRD 已列的候选**：否决，产品负责人有明确偏好，应给出实测结论而不是凭推测排除。

## Consequences

- 开始评测前必须先核实三件事并记录来源：该模型是否有可用的 ONNX 导出或 sherpa-onnx 支持；鸿蒙 NEXT、iOS、Android 三端是否都能加载；权重的许可证是否允许随应用分发。任何一项不成立，该候选在对应平台标为不可用，不得用其他模型的结果代替。
- 如果它不能经 sherpa-onnx 运行，而要引入另一套推理运行时，需要单独写 ADR，因为这会改变 PRD 第 15.1 节“共享本地 ASR”的选型。
- 评测结果按 FR-ASR-003 的检查项记录，并按 FR-ASR-004 固定模型文件、哈希和许可证。
- 默认模型可以按平台不同：若 1.7B 只在部分手机上达标，允许该平台用它，其他平台用较小的模型，但要在模型清单里写明。
