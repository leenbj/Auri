# ADR-0016：手势决定录音的开始与结束，VAD 只在采集会话内过滤静音

产品负责人要求“有人说话时自动录音，无人说话则不需要录音”。这句话有两种读法，决定采用第一种：Capture Session 的开始和结束仍只由明确命令（耳机手势、屏幕操作）、系统中断或时长上限决定；VAD 只在一次 Capture Session 内部工作，丢弃无人声的片段并切分语句，静音持续多久都不会结束会话。不做“一直监听，有人声就自动开录”。

## Considered Options

- **常开监听，由 VAD 触发开始录音**：否决。这要求麦克风在用户没有发出命令时长期开启，与 Control Mode“待命不代表麦克风已开”的定义冲突；iOS 后台不能新建录音会话（ADR-002），做不到；也违反“不得长期偷录再丢弃”的约束。
- **静音超过阈值自动结束会话**：否决，违反 FR-REC-006，且 HFP 数字静音会被误判为用户停止。

## Consequences

- 与 FR-REC-006 一致，不需要改该条的要求，只需补充“VAD 可以丢弃会话内的静音片段”。
- VAD 的丢弃动作发生在路由确认之后；Quarantine 里未确认路由的帧仍按 FR-REC-001/002 处理，不因 VAD 判为人声而提前落盘。
- 被丢弃的静音不进入 Recording，因此 Recording 的时长短于 Capture Session 的实际时长。Recording 是否保留各语音片段在原始时间线上的起止时间，在 ADR-004（录音容器与恢复边界）里决定。
- VAD 的误丢（把轻声说话当静音）会造成内容丢失，需要在 ASR 评测音频里加入轻声、远讲、噪声样本，并给出前后保留的余量参数。
- iOS 上录音中的停止方式仍按 ADR-0014，不受本决策影响。
