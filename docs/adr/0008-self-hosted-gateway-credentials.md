# ADR-008：自托管单用户网关，设备与 Agent 凭证分离签发

V1 网关由用户自托管、常开，手机经带正式 TLS 证书的公网域名访问；设备与 Agent 的身份分离。每个 Destination 绑定一套专属的静态 Bearer 凭证（带作用域、可撤销、库内只存哈希），配到 Agent 一侧；手机用网关命令行生成的一次性、短时有效的配对码换取设备令牌。设备令牌除录音写入与同步外，还带管理 Destination 的权限，使 App 能创建 Destination、一次性显示或轮换其凭证；App 只与网关通信，不直连任何 Agent。OAuth 2.1 留到用户管理系统上线时再做。

## Considered Options

- **设备令牌只有写入权限，Destination 只能在主机命令行管理**：否决，产品负责人要求在 App 内自行配置 Agent 连接，每加一个 Agent 就登录主机不可接受。
- **手机直连 Agent，跳过网关**：否决，手机会持有 Agent 凭证，并绕过网关的授权、幂等与租约。
- **V1 即做 OAuth 2.1**：否决，V1 只有一个 User，Hermes 官方支持静态 headers，FR-MCP-005 允许受控私有客户端使用服务凭证；Tenant 由认证映射得出（ADR-0013），日后升级不改数据模型。

## Consequences

- 设备令牌被盗的影响面变大：持有者能创建 Destination 并读出新凭证。因此创建、显示、轮换凭证必须经本机生物识别二次确认，新凭证只显示一次，设备令牌存入平台安全存储。二次确认只在设备端强制，网关无法验证；它防的是被他人借用的已解锁手机，不防已被提取的令牌。
- 网关命令行始终可吊销任一设备或凭证，并能列出某台设备创建过的凭证供审查；吊销设备不会自动吊销它创建的凭证，因为那些凭证可能正被 Agent 合法使用。
- 新设备的配对码只能由网关命令行生成。
- 同一个 Hermes 接多个用途时，其配置里有多条 MCP 条目（每个 Destination 一条）。
- PRD 第 17.2 节需增补配对、Destination 管理、凭证签发/轮换/吊销接口，由合同负责人合并。
