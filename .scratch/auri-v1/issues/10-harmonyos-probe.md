# 10: 鸿蒙探针

**What to build:** 同 Android 探针，对象是鸿蒙 NEXT。另外验证手机能否用 mDNS 在局域网内找到服务。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Needs human:** 需要产品负责人在 Mac 和真机上构建、装机、操作并取回日志；Agent 负责写代码、写操作步骤和整理结论。没有真机结果的项标 `NOT_RUN` 或 `BLOCKED_EXTERNAL`，不得用模拟代替。

- [ ] 只用公开接口；不播放无声音频保活，不伪造通话，不用私有接口；路由证据不满足时拒绝录音，不改用手机麦克风
- [ ] 逐场景记录：前台开始和停止、蓝牙麦克风已激活后再次手势能否停止、录音中锁屏、停止后锁屏再开始、进程被杀后开始
- [ ] 记录应用实际收到的平台事件和系统观测到的输入路由
- [ ] 每个“耳机 × 手机 × 系统版本 × 场景”单独给出状态和证据等级，未测的保持未测试
- [ ] 探针工程可复现，构建和取日志的步骤写清楚；原始日志不入库，入库的是脱敏后的结论
- [ ] 记录所用的 SDK 版本和最低系统版本要求
- [ ] 给出 mDNS 是否可用的真机结论；不可用时该平台只用配对时记下的地址
- [ ] 若看到 contracts 里没有的平台事件，提出合同变更
