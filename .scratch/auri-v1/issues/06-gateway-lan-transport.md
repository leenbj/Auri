# 06: 网关：局域网传输

**What to build:** Gateway 只在局域网提供服务：自己生成密钥和证书，在配对载荷里给出地址和公钥指纹，并广播 mDNS 服务，客户端凭公钥指纹确认它的身份（ADR-0018）。

**Blocked by:** 01 网关：配对并入库

**Status:** ready-for-agent

- [ ] Gateway 首次启动生成密钥和自签证书，之后复用同一把密钥；用同一把密钥续签证书后公钥指纹不变
- [ ] 配对载荷符合 contracts，包含地址、mDNS 服务类型、公钥指纹、配对码和过期时间，可显示为二维码
- [ ] Gateway 只监听局域网和本机地址
- [ ] Gateway 在局域网内广播 mDNS 服务，客户端能据此找到它
- [ ] 提供一个参考客户端的测试：公钥指纹相符才连接；不符时拒绝连接，且没有“忽略并继续”的路径
- [ ] 除本机开发回环外不接受明文连接
- [ ] 证书有效期和续签步骤写进运维说明
