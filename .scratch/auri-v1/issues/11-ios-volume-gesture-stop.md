# 11: iOS：音量手势停止的设计与复测

**What to build:** ADR-0014 决定 iOS 录音中用音量手势停止，但手势的具体规则还没定。定出规则并在真机上验证，同时查清免费签名是否支持所需的后台音频能力。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Needs human:** 需要产品负责人在 Mac 和真机上构建、装机、操作并取回日志；Agent 负责写代码、写操作步骤和整理结论。没有真机结果的项标 `NOT_RUN` 或 `BLOCKED_EXTERNAL`，不得用模拟代替。

- [ ] 手势规则写成决策记录，说明如何区分“停止”和普通调音量
- [ ] 真机覆盖：音量在顶部、底部、中间；锁屏；后台
- [ ] 记录误停和漏停的实际情况
- [ ] 给出锁屏下是否有屏幕停止入口的结论
- [ ] 给出免费个人团队签名是否支持后台音频的结论；不支持时标为外部阻塞并说明需要付费账号
- [ ] 不使用通话类框架、私有蓝牙协议或保活手段
