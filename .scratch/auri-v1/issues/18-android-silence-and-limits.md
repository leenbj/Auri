# 18: Android：静音过滤、无语音与时长上限

**What to build:** 没人说话的片段不保存，但保留各语音片段在原始时间线上的位置。整段没说话时留下一条“无语音”的 Record。到达时长上限自动停止。

**Blocked by:** 16 Android：屏幕按钮录一段并转成文字

**Status:** ready-for-agent

**Needs human:** 需要产品负责人在 Mac 和真机上构建、装机、操作并取回日志；Agent 负责写代码、写操作步骤和整理结论。没有真机结果的项标 `NOT_RUN` 或 `BLOCKED_EXTERNAL`，不得用模拟代替。

- [ ] 静音片段不落盘；录音结果记录采集时长、语音时长和每个语音片段的起止位置
- [ ] 停顿多久都不结束录音
- [ ] VAD 只在路由确认之后工作，不让未确认的音频提前落盘
- [ ] 整段无人声时产生一条没有 Revision 的 Record，界面显示“无语音”
- [ ] 时长上限可设置，默认 30 分钟，最多 120 分钟；到点前一分钟提示，到点自动停止并保存，不自动续录
- [ ] 结束原因被正确记录
- [ ] 录音结果通过合同和语义规则校验
