# 07: 网关：运维

**What to build:** 用户在电脑上能管理设备和凭证、清理丢失手机留下的内容，并能安全地备份、恢复和升级。

**Blocked by:** 04 网关：入库的拒绝规则与删除

**Status:** ready-for-agent

- [ ] 命令行能列出已配对的设备和每台设备创建过的凭证
- [ ] 命令行能吊销设备或单个凭证；吊销设备不自动吊销它创建的凭证
- [ ] 命令行能删除已吊销设备名下的 Record，效果与设备自己删除一致
- [ ] 备份后在另一个目录恢复，数据和凭证哈希完整可用
- [ ] 旧版本数据库在升级时自动迁移；迁移失败时保留原数据
- [ ] 日志不包含正文和凭证
