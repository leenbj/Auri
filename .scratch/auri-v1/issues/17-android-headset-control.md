# 17: Android：耳机手势控制与校准

**What to build:** 用户开启 Control Mode 后用耳机手势开始和停止录音。校准向导带用户走完完整闭环，生成这副耳机在这台手机上的 Headset Profile。

**Blocked by:** 16 Android：屏幕按钮录一段并转成文字

**Status:** ready-for-agent

**Needs human:** 需要产品负责人在 Mac 和真机上构建、装机、操作并取回日志；Agent 负责写代码、写操作步骤和整理结论。没有真机结果的项标 `NOT_RUN` 或 `BLOCKED_EXTERNAL`，不得用模拟代替。

- [ ] 没开 Control Mode 时媒体事件不触发录音
- [ ] 平台事件归一化为带来源和序号的控制事件；一次手势不会先开始又立刻停止
- [ ] 准备阶段的停止命令能取消，不被防抖吞掉；封存中的过时切换命令不会开始下一段
- [ ] 校准向导覆盖：不录音时的事件、录音中再次手势、停止后再次开始、锁屏
- [ ] 校准产出的 Headset Profile 通过合同校验；没测的能力保持未测试
- [ ] 开始、停止、启动失败有可区分的反馈；屏幕上始终有手动按钮兜底
- [ ] 真机上完成一次校准并用手势录一段
