# 15: 本地转录：三端评测并定默认模型

**What to build:** 候选模型在三台目标手机上用同一批音频对比，据此定下默认模型（ADR-005）。

**Blocked by:** 14 本地转录：一台 Android 手机上跑通；12 G0 汇总

**Status:** ready-for-agent

**Needs human:** 需要产品负责人在 Mac 和真机上构建、装机、操作并取回日志；Agent 负责写代码、写操作步骤和整理结论。没有真机结果的项标 `NOT_RUN` 或 `BLOCKED_EXTERNAL`，不得用模拟代替。

- [ ] 三端都能加载并运行候选模型；加载不了的在该平台标为不可用

- [ ] 默认模型的决策记录附数据和许可结论；允许各平台默认不同
- [ ] 真实口述音频不入库
