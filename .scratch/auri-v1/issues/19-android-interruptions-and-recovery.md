# 19: Android：中断、断连与崩溃恢复

**What to build:** 录音中耳机断开、来电或应用被杀时，已录的部分被保存并标为被截断。应用重新打开后能找回片段，且不会自己开始录音。

**Blocked by:** 16 Android：屏幕按钮录一段并转成文字

**Status:** ready-for-agent

**Needs human:** 需要产品负责人在 Mac 和真机上构建、装机、操作并取回日志；Agent 负责写代码、写操作步骤和整理结论。没有真机结果的项标 `NOT_RUN` 或 `BLOCKED_EXTERNAL`，不得用模拟代替。

- [ ] 路由变化或耳机断开时立即关闸，保存已确认的部分，标为被截断
- [ ] 系统中断后不自动续录
- [ ] 录音分段写入；杀进程后重新打开能恢复出已写入的片段
- [ ] 进程恢复后采集处于未待命状态，不自动开麦
- [ ] 权限被撤销时安全结束
- [ ] 存储空间不足时安全结束并保留可恢复的片段
- [ ] 真机上分别验证断开耳机、来电、杀进程三种情况
