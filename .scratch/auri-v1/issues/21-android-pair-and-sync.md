# 21: Android：配对并把文字送到网关

**What to build:** 用户扫码把手机配对到自己电脑上的 Gateway。在局域网内时文字直接入库；离开局域网时显示“等待网关”，回来后自动补传。

**Blocked by:** 16 Android：屏幕按钮录一段并转成文字；04 网关：入库的拒绝规则与删除；06 网关：局域网传输

**Status:** ready-for-agent

**Needs human:** 需要产品负责人在 Mac 和真机上构建、装机、操作并取回日志；Agent 负责写代码、写操作步骤和整理结论。没有真机结果的项标 `NOT_RUN` 或 `BLOCKED_EXTERNAL`，不得用模拟代替。

- [ ] 扫码完成配对，设备令牌存入平台安全存储
- [ ] 每次连接核对 Gateway 公钥指纹；不符时拒绝连接并提示重新配对，没有“忽略并继续”
- [ ] 先连配对时记下的地址，连不上用 mDNS 查找
- [ ] 发布 Revision 和创建待同步任务在同一个本地事务里完成；待同步任务在应用重启后保留
- [ ] 同步状态机的事件序列样本全部通过
- [ ] 界面区分三种情况：等待网关、稍后重试、需要用户处理
- [ ] 提交结果不确定时先查询再决定是否重发，不产生重复记录
- [ ] 真机上验证：在局域网内入库；断开 Wi-Fi 后录音，重连后自动补传
