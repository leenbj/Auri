# 16: Android：屏幕按钮录一段并转成文字

**What to build:** 用户点开始，应用确认音频来自所选耳机后才保存；点停止后自动转成文字，记录库里出现一条带文字的 Record。耳机麦克风不可用时拒绝录音。这是手机端的第一条完整路径，也是另外两端的样板。

**Blocked by:** 09 Android 探针；14 本地转录：一台 Android 手机上跑通

**Status:** ready-for-agent

**Needs human:** 需要产品负责人在 Mac 和真机上构建、装机、操作并取回日志；Agent 负责写代码、写操作步骤和整理结论。没有真机结果的项标 `NOT_RUN` 或 `BLOCKED_EXTERNAL`，不得用模拟代替。

- [ ] 采集协调器实现采集状态机，通过控制、采集、转录三个适配器接口接触系统
- [ ] contracts 里采集状态机的事件序列样本全部通过（用假适配器）
- [ ] 路由确认前的音频只在内存里，确认失败时丢弃，不落盘、不转录
- [ ] 耳机麦克风不可用时不录音并给出原因；任何情况下不改用手机麦克风
- [ ] 取消后迟到的回调、旧代次的写入、路由纪元失配都不能改写当前会话（有测试）
- [ ] 停止后自动转录，产生一条 Record 和第一个 Revision，写明所用模型
- [ ] 首页分开显示耳机连接、实际输入来源、当前录音状态
- [ ] 真机上用 FreeClip 录一段并得到文字
