# 20: Android：模型管理与转录调度

**What to build:** 用户在应用里下载和管理转录模型。转录在后台排队进行，不影响新的录音。

**Blocked by:** 16 Android：屏幕按钮录一段并转成文字

**Status:** ready-for-agent

**Needs human:** 需要产品负责人在 Mac 和真机上构建、装机、操作并取回日志；Agent 负责写代码、写操作步骤和整理结论。没有真机结果的项标 `NOT_RUN` 或 `BLOCKED_EXTERNAL`，不得用模拟代替。

- [ ] 模型列表显示大小、所需空间、语言和许可证入口
- [ ] 下载可暂停和恢复；校验通过后才原子启用；校验失败不加载；更新失败保留旧模型
- [ ] 转录状态机的事件序列样本全部通过
- [ ] 没有模型或资源不足时任务等待并显示原因，条件恢复后继续，不无限重试
- [ ] 转录进行时开始新录音不掉帧
- [ ] 重新转录产生新的 Revision，旧的保留
- [ ] 没有识别出语音时如实说明，不产生文字
